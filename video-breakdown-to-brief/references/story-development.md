# Story development: from topic or breakdown to screenplay

Use this reference for `拉片后做项目` and `生成新脚本`. The result is a **故事剧本** before a production screenplay. A story script explains why events happen and why a viewer cares; the four-beat script and shots later decide what is filmed or generated.

## A. Choose the source route

### Route A — build from a breakdown

Use only verified evidence from the reference. Transfer a method of rhythm or conflict, not the reference's surface.

| Reference evidence | Transferable rhythm / conflict method | Creator's own person, material, and setting | Intended viewer effect |
| --- | --- | --- | --- |
|  |  |  |  |

Examples of transferable methods: delay the answer to a visible question; let a small object become the entry point; put an ordinary routine under pressure; let sound arrive before the image changes; reveal the choice only after the cost is clear.

### Route B — build from the creator's topic

Start with what the creator can actually access, not a broad theme.

| Topic / real material | Person now | Immediate want | Obstacle / pressure | What may be lost | Visible ending change |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

## B. Story atom and one-sentence story law

First write the story atom. Each item must be concrete.

| Person | Normal state | Immediate want | Obstacle | Cost | Choice | Visible result |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |

Then write one sentence with this pattern:

```text
当【谁】在【原本状态】中想要【立即目标】时，
【反差性事件 / 阻碍】让他 / 她可能失去【代价】，
于是不得不【可见的选择】，最后【可见或可听见的变化】。
```

### One-sentence story check

- A viewer can identify one person and one immediate want: 可用 / 需修改
- The obstacle is an event, person, condition, or choice—not an abstract mood: 可用 / 需修改
- The cost explains why the choice matters: 可用 / 需修改
- The ending shows a change instead of explaining a theme: 可用 / 需修改
- The creator's own people, setting, and material remain distinct from any reference: 可用 / 需修改

## C. Empathy and contrast design

Empathy is not “make the character sad.” Give the viewer a readable human need, a small vulnerability, and a cost attached to the choice. Contrast prevents the story from moving on one flat emotional note.

| Design item | Question | Concrete answer | How the viewer sees or hears it |
| --- | --- | --- | --- |
| Empathy point | What ordinary need or fear can a viewer recognise? |  |  |
| Vulnerability | What makes the character unable to solve this easily? |  |  |
| Contrast 1 | What does the viewer expect, and what actually happens? |  |  |
| Contrast 2 | What outer action conflicts with the inner feeling? |  |  |
| Meaningful choice | What action costs the character something? |  |  |

For a 30–60 second story, use one clear empathy point and one or two contrasts. Add more only if the duration can support them.

## D. Double-curve design

The two curves run on the same time axis but answer different questions.

| Curve | What it measures | Viewer question | Typical movement |
| --- | --- | --- | --- |
| **龙骨曲线：故事曲线** | conflict pressure and cause–effect | “What will happen next?” | normal state → pressure → choice → result |
| **砖瓦曲线：情绪曲线** | feeling, release, surprise, warmth, discomfort, or aftertaste | “What does this feel like now?” | may rise, fall, pause, or reverse independently of plot pressure |

Do not force the two lines to peak at the same time. A story may have high pressure with controlled emotion, then lower pressure with a strong emotional aftershock. This contrast creates breathing room and makes the final image more memorable.

Score each moment from `0` (low) to `5` (high), then explain the cause of each movement.

| Story node | Time % | What happens | 龙骨 pressure 0–5 | 砖瓦 emotion 0–5 | Emotional quality | Why the two curves move this way |
| --- | --- | --- | --- | --- | --- | --- |
| N1 | 0% |  |  |  |  |  |
| N2 | 20–30% |  |  |  |  |  |
| N3 | 45–55% |  |  |  |  |  |
| N4 | 65–80% |  |  |  |  |  |
| N5 | 100% |  |  |  |  |  |

### Double-curve check

- The story pressure has at least one clear rise caused by an obstacle: 可用 / 需修改
- There is a readable choice before the ending: 可用 / 需修改
- The emotional curve has at least two distinct changes, not one steadily rising line: 可用 / 需修改
- Each curve movement is caused by a visible event, sound, or relation: 可用 / 需修改
- The final emotional state is earned by the story choice: 可用 / 需修改

## E. Emotional hooks and conflict points

An emotional hook is a designed moment that gives the viewer a reason to lean in, not a random sad image. A hook may be a question, an unexpected contradiction, a threatened small need, a delayed response, an object whose meaning changes, or a quiet result after pressure.

For a 30–60 second short, suggest **2–4 hooks** and **2–3 conflict points** unless the creator confirms another scale. Label these numbers as **暂定** until the duration is fixed.

| ID | Type | Position / node | Setup | Viewer question or feeling | Conflict it touches | Resolution / carry-forward |
| --- | --- | --- | --- | --- | --- | --- |
| H1 | hook |  |  |  |  |  |
| C1 | conflict |  |  |  |  |  |
| H2 | hook |  |  |  |  |  |
| C2 | conflict |  |  |  |  |  |
| H3 | hook / aftertaste |  |  |  |  |  |

Avoid stacking every hook at the opening. Let at least one hook change the viewer's understanding after the trigger or after the choice.

## F. Story script: causal sequence before production script

Write 4–6 story nodes. This is not yet a shot list. It explains event, motive, consequence, and emotional movement.

| Node ID | Setup / event | Character wants | Obstacle / conflict | Choice or response | Consequence | 龙骨 change | 砖瓦 change | Hook / contrast ID |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| N1 |  |  |  |  |  |  |  |  |
| N2 |  |  |  |  |  |  |  |  |
| N3 |  |  |  |  |  |  |  |  |
| N4 |  |  |  |  |  |  |  |  |
| N5 |  |  |  |  |  |  |  |  |

### Story-script check

- Each node is caused by, or answers, the previous node: 可用 / 需修改
- At least one response is a costly or revealing choice: 可用 / 需修改
- The final consequence changes a relationship, situation, or self-understanding in a visible way: 可用 / 需修改
- The story can be told without relying on an explanatory title card: 可用 / 需修改

## G. From story script to production script

Map before writing the four beats. If a story node has no production beat, it will not be visible. If a beat has no story node, it may be decoration rather than narrative.

| Story node | What must become visible or audible | Four-beat ID | Required shot function | Emotional job | Asset / continuity requirement |
| --- | --- | --- | --- | --- | --- |
| N1 |  | B1 建立 | establish person / space / need | first connection |  |
| N2 |  | B2 触发 | reveal obstacle / question | lean-in |  |
| N3 |  | B3 转变 | show choice / action | release or surprise |  |
| N4–N5 |  | B4 余韵 | leave result / aftertaste | lingering feeling |  |

## H. Step-by-step generation protocol

Generate in the following order. Present each stage as a separate result so a creator can correct the story before production detail multiplies.

1. **Choose route** — breakdown method or creator topic.
2. **Fill story atom** — person, want, obstacle, cost, choice, result.
3. **Offer one story sentence** — revise until it passes the check.
4. **Design empathy and contrast** — identify what the viewer recognises and what reverses expectation.
5. **Draw dual curves** — score and explain five nodes, then place hooks and conflict points.
6. **Write story script** — 4–6 causal nodes.
7. **Map to four beats** — only then write the production script, shots, assets, and prompts.

Before moving to the next stage, state: `可用 / 需修改 / 缺资料`, the evidence, and the single highest-priority question. Do not generate competing story directions, prompt variants, or a variable-test matrix unless the creator explicitly requests alternatives.
