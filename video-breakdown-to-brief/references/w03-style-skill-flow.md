# W03 视觉方法：为视频创作做内容输出辅助

W03 在这个 Skill 里是一层轻量的视觉规则方法：把参考片、参考图或项目素材中的视觉方法提取出来，再叠加到故事、四拍、镜头、空间、资产和提示词输出中，让同一项目的内容更统一。

## 什么时候使用

当用户提出“参考这个片子的视觉感觉”“提取 Style DNA”“建立 Style Skill”“让镜头保持一致”“把风格规则加到我的提示词”或“辅助生成视频内容”时，使用本流程。

W03 不重写用户已经确认的故事、人物、产品或空间几何，也不要求自动生成完整的视觉圣经或四镜测试，除非用户明确要求。

## 最小输入

- 已确认的主题、故事剧本、四拍或镜头任务；
- 可用的参考片、参考图、产品图或已有生成结果（可没有）；
- 用户已经锁定的人物、场景、产品、品牌和画幅要求；
- 本轮真正要输出的内容，例如故事、脚本表、镜头表、资产提示词或逐镜视频提示词。

如果 W02 内容或参考素材缺失，写 `缺少资料`；不要为了填满风格字段而猜测镜头、模型、版权或制作事实。

## 四步轻量流程

### 1. 提取 Style DNA

只选本项目真正有用的 3–5 个维度，不必每次填满九格。可选维度：色彩、光线、构图、镜头、材质、运动、主体锚点、空间锚点、声音 / 节奏。

每条记录用这一行：

```text
看到或听到的证据 → 可迁移的方法 → 用在我的内容哪里 → 希望观众感受到什么
```

参考片结论标记为 `画面可见`、`分析判断` 或 `缺少资料`。迁移的是节奏、构图、光线、材质、信息延迟和声音关系，不复制参考片的角色、剧情、品牌资产或标志性画面。

### 2. 写成 Style Grammar

把抽象的“高级、电影感、梦境、氛围感”改成能检查的规则：

| 类型 | 建议内容 |
| --- | --- |
| Must Keep | 3–5 条每个镜头都应尽量保持的视觉关系 |
| Can Change | 人物动作、故事事件、产品卖点、地点和镜头任务等内容变量 |
| Negative | 3–5 条明确不要出现的漂移，例如过饱和、塑料皮肤、无因炫光、错误产品结构 |

同时锁定最少三个锚点：主体 / 产品、空间、光线。只有用户确认后的创作设定，才能写成 `固定锚点`。

### 3. 把规则加进内容输出

先写用户要的内容，再在每个交付物上调用同一组规则：

- 故事或脚本：用视觉规则服务情绪、冲突和信息顺序，不把规则写成剧情；
- 四拍与镜头表：在每拍 / 每镜注明需要保持的主体、空间、光线和材质关系；
- 资产图提示词：只生成角色、产品、场景或参考表，不把资产提示词写成整段剧情；
- 四拍视觉提示词：每拍只写该拍要读懂的视觉变化；
- 逐镜视频提示词：沿用同一组锚点，只写这一镜的动作、景别、运镜、声音和交接；时间码必须沿用 W02 镜头表。
- 空间调度 / 机位 / 关键帧：只叠加视觉规则，不改写 W02 的地标、站位、镜头位置或时间码。
- 动态预演规格：只叠加风格与声音节奏建议，不默认生成视频文件。

推荐的调用结构：

```text
内容任务 + 已确认资产锚点 + Style Grammar + 本镜新增动作 / 信息 + 连续性限制
```

不要每个镜头从零重写一套风格词，也不要用 Style Skill 改掉用户已经确认的主题和故事选择。

### 4. 做一次轻量一致性检查

只检查与本次输出有关的项目：

- 同一主体 / 产品的外观、比例和关键细节是否一致；
- 同一空间的入口、方向、机位关系是否能接上；
- 色彩、光线、材质和运动是否仍符合 Must Keep；
- Negative 是否被某个镜头或资产提示词违反；
- 画面变化是否来自故事任务，而不是无意的风格漂移。

发现问题时只返回：`问题 → 证据 → 最小修改 → 需要重写的行`。只有用户要求或风险较高时，才追加四镜测试或单变量实验。

## 轻量 Style Skill 输出结构

当用户需要把这套规则保存为 Skill，输出以下最小结构即可：

```json
{
  "version": "W03-v1",
  "title": "",
  "oneLineVisualDirection": "",
  "mustKeep": [],
  "canChange": [],
  "negative": [],
  "anchors": {
    "subjectOrProduct": "",
    "space": "",
    "light": ""
  },
  "promptTemplate": ""
}
```

需要文件时再导出：`style-skill.json`、`prompt-template.txt`、`negative-rules.txt`。没有填写的字段保留为 `缺少资料`，不伪造参数。

## 与已有视频创作流程的关系

W03 只增加“视觉规则层”，不替代前面的故事和生产表：

```text
故事原子 / 一句话故事
→ 四拍与镜头表
→ 空间调度与机位文字排布
→ W03 Style DNA + Style Grammar
→ 资产图提示词、四拍视觉提示词、关键帧提示词、逐镜视频提示词
→ 动态预演规格与一致性检查
```

不要默认展开完整 Visual Bible、额外验证或长篇理论说明。
